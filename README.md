# Классификация тональности отзывов

Python-проект определяет тональность русскоязычного отзыва по трём классам — **позитивный**, **нейтральный** и **негативный**. Командная строка принимает один текст или CSV с отзывами. В репозитории есть обученная модель, скрипт для воспроизведения обучения и отчёт с метриками.

## Быстрый старт

Понадобится Python 3.12. После клонирования репозитория запустите команды из его корня.

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m sentiment predict --text "Отличное качество, ткань мягкая, покупкой очень довольна!"
```

В PowerShell виртуальное окружение активируется командой `.\.venv\Scripts\Activate.ps1`.

Команда напечатает `позитивный`. По умолчанию она использует [models/sentiment.joblib](models/sentiment.joblib).

### Пакетная классификация

Сохраните отзывы в UTF-8 CSV с запятыми и колонкой `review`. Можно добавить свои колонки, например `id`.

```csv
id,review
1,"Отличное качество, ткань мягкая, покупкой очень довольна!"
2,"Размер подошёл, но ткань тоньше, чем ожидала. В целом нормально."
3,"Ужасное качество: швы разошлись после первой носки."
```

```bash
python -m sentiment predict --input reviews.csv --output predictions.csv
```

В выходном файле сохраняются исходные колонки и порядок строк. Добавляется колонка `sentiment` с результатами `позитивный`, `нейтральный` и `негативный` для примера выше. Входные тексты должны быть непустыми, а заголовок `sentiment` зарезервирован для результата.

## Данные и обучение

RuReviews содержит 90 000 русскоязычных отзывов о женской одежде и аксессуарах, по 30 000 на класс. Авторы получили метки из оценок покупателей. Исходный файл хранит столбцы `review` и `sentiment` с разделителем табуляцией. Источники — [репозиторий RuReviews](https://github.com/sismetanin/rureviews/tree/2f6e61d30dc6c58ba47dce72e5803e1f0a3f38a7), [статья С. Сметанина и М. Комарова](https://doi.org/10.1109/CBI.2019.00062) и [лицензия датасета Apache 2.0](https://github.com/sismetanin/rureviews/blob/2f6e61d30dc6c58ba47dce72e5803e1f0a3f38a7/LICENSE).

```bash
python -m sentiment train
```

Команда скачивает зафиксированную версию датасета в `data/`, проверяет SHA-256 и сохраняет модель в `models/sentiment.joblib`, а метрики в `reports/metrics.json`. Файл скачивается при первом запуске. Локальный TSV того же формата можно передать через `--data`. Пути для результатов задаются через `--model` и `--metrics`.

Перед разбиением тексты приводятся к единой форме Unicode и регистру, лишние пробелы убираются, а `neautral` в исходных метках исправляется на `neutral`. Удалены одна пустая запись, 1 156 повторов с одинаковой меткой и 2 775 записей с противоречивыми метками. Осталось 86 068 уникальных текстов.

Стратифицированное разбиение 80/20 с `random_state=42` дало 68 854 отзыва для обучения и 17 214 для теста. Модель использует словные униграммы и биграммы, символьные n-граммы длиной 3–5 внутри слов, взвешивание TF-IDF и линейный SVM (`LinearSVC`). Словари и веса TF-IDF вычисляются только по обучающей выборке.

## Результаты на тестовой выборке

| Модель | Accuracy | Macro-F1 |
| --- | ---: | ---: |
| Базовая модель, предсказывающая самый частый класс | 33,75% | 0,168 |
| TF-IDF + LinearSVC | **73,06%** | **0,730** |

Macro-F1 усредняет F1 по трём классам с одинаковым весом. Полный отчёт находится в [reports/metrics.json](reports/metrics.json).

| Класс | Precision | Recall | F1 | Отзывов |
| --- | ---: | ---: | ---: | ---: |
| Позитивный | 0,867 | 0,865 | 0,866 | 5 810 |
| Нейтральный | 0,616 | 0,619 | 0,618 | 5 681 |
| Негативный | 0,706 | 0,705 | 0,705 | 5 723 |

### Матрица ошибок

Строки соответствуют истинным меткам, столбцы — предсказаниям.

| Истинная метка | Позитивный | Нейтральный | Негативный |
| --- | ---: | ---: | ---: |
| Позитивный | **5 026** | 639 | 145 |
| Нейтральный | 631 | **3 518** | 1 532 |
| Негативный | 137 | 1 554 | **4 032** |

Наибольшее число ошибок приходится на нейтральные и негативные отзывы. Оценка измерена на отзывах об одежде и аксессуарах с почти равными долями классов. Для отзывов об услугах, компаниях и других категориях товаров качество может отличаться и требует отдельной оценки на размеченных данных соответствующей тематики.

| Путь | Назначение |
| --- | --- |
| `sentiment/data.py` | Загрузка датасета, проверка и подготовка данных |
| `sentiment/model.py` | Обучение, оценка и сохранение модели |
| `sentiment/__main__.py` | Команды обучения и классификации |
| `models/sentiment.joblib` | Обученный конвейер TF-IDF + LinearSVC |
| `reports/metrics.json` | Статистика данных, результаты и матрицы ошибок |
| `requirements.txt` | Версии зависимостей для воспроизводимости |
